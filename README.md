# Экономически обоснованный порог переобучения кредитных скоринговых моделей

Код и результаты исследования: когда переобучение скоринговой модели окупается
и какой сигнал мониторинга надёжнее — календарь, PSI или калибровка.

Работа выполняется в НИУ ИТМО (бизнес-информатика) в рамках научно-исследовательского
семинара. Статья готовится к подаче в рецензируемый журнал.

## Исследовательский вопрос

При каких условиях переобучение скоринговой модели по сигналу мониторинга
экономически предпочтительнее переобучения по календарю и каким должен быть
порог срабатывания?

### Гипотезы

| | Формулировка | Статус |
|---|---|---|
| **H1** | Существует точка безубыточности C\*: при стоимости переобучения ниже C\* стратегия обновления повышает чистую прибыль по сравнению с отсутствием обновления | Подтверждена |
| **H2** | Триггерная стратегия обеспечивает прибыль не ниже лучшей календарной | Подтверждена слабо (ДИ пересекает ноль) |
| **H3** | Оптимальный порог триггера ниже отраслевого стандарта | Подтверждена: 0,02–0,05 против 0,10/0,25 |

## Данные

Открытый набор [Lending Club 2007–2018](https://www.kaggle.com/datasets/wordsforthewise/lending-club)
(файлы одобренных и отклонённых заявок). В репозиторий данные **не включены**:
исходные файлы занимают около 630 МБ. Скачайте оба архива с Kaggle и положите
в каталог `data/`:

```
data/accepted_2007_to_2018Q4_csv.gz
data/rejected_2007_to_2018Q4_csv.zip
```

Набор публиковался автором, который предупредил, что обновлять его больше не
сможет из-за условий использования Lending Club; файл отклонённых заявок с сайта
кредитора удалён примерно в 2019 году. Сохраните свою копию.

Окно наблюдения — кредиты сроком 36 месяцев, выданные с января 2009 по декабрь 2015.
Более поздние когорты не используются: у них ещё не завершился срок, и доля дефолтов
смещена вниз.

## Методология

**Экономическая основа** — регуляторная формула ожидаемых потерь
`EL = PD × LGD × EAD` (Basel II/III). Прибыль не прогнозируется, а берётся из
данных: `cash_result = total_pymnt + recoveries − funded_amnt`.

**Определение дефолта.** 12-месячный дефолт выводится из даты последнего платежа:
заёмщик перестал платить в первые 12 месяцев после выдачи. Это соответствует
горизонту PD в Базеле.

**Лаг наблюдаемости.** Переобучение использует только когорты, выданные не позже
чем за 18 месяцев до текущего момента (12 месяцев на дефолт плюс около 5 на
признание списания). Модель не видит будущего.

**Защита от утечки.** Из признаков исключены грейд, подгрейд и ставка — это
собственная оценка риска кредитора, — а также все поля, заполняемые после выдачи.
Медианы, границы интервалов и порог отсечения подбираются внутри каждого
обучающего окна. Контрольная проверка: AUC 0,66, что соответствует литературе
для скоринга без грейда.

**Модель** — логистическая регрессия (классическая скоринговая карта).
Разреженные поля `mths_since_*` разбиваются на интервалы, пропуск трактуется как
отдельная категория «события не было».

### Сравниваемые стратегии

| | Стратегия | Правило обновления |
|---|---|---|
| S1 | Без переобучения | Модель обучается один раз; базовый сценарий |
| S2 | Календарь, 3 месяца | Каждые 3 месяца горизонта |
| S3 | Календарь, 6 месяцев | Каждые 6 месяцев горизонта |
| S4a | PSI по скору | Срабатывание при PSI распределения скора выше θ |
| S4b | PSI по заявкам | То же по входящему потоку заявок (одобренные + отклонённые) |
| S4c | Калибровка | Срабатывание при расхождении предсказанной и фактической PD выше δ |

После каждого переобучения действует период охлаждения в 3 месяца.

## Результаты

### Выгода против S1, млн $ (тестовый период 2014–2015)

| Стратегия | окно 12 | окно 18 | окно 24 | окно 36 |
|---|---|---|---|---|
| S2 календарь 3 мес. | 24,41 | 31,16 | **37,73** | 32,63 |
| S3 календарь 6 мес. | 21,22 | 27,05 | 34,32 | 29,09 |
| S4a PSI по скору θ=0,10 | **0** | **0** | 38,93 | 32,34 |
| S4b PSI по заявкам θ=0,10 | 25,53 | 29,34 | 36,58 | 29,59 |
| S4c калибровка δ=0,15 | 25,20 | 27,48 | 34,13 | 25,94 |

### Три вывода

**1. Деградация происходит в калибровке, а не в различающей способности.**
За два года AUC не падает (0,656 → 0,674), но предсказанная PD держится около
12,4 %, пока фактическая растёт с 12,2 % до 15,1 %. Мониторинг по AUC такую
проблему не увидел бы.

**2. Отраслевой порог PSI на этих данных не работает.** При θ = 0,25 сигнал по
распределению скора не срабатывает ни разу ни при одном окне обучения. При
θ = 0,10 он молчит на окнах 12 и 18 месяцев, то есть стратегия вырождается в S1.
Оптимальный порог — 0,02–0,05.

**3. Важно не сколько раз обновлять модель, а когда.** Одно переобучение по
сигналу (S4a, окно 24) дало больше, чем четыре по календарю.

### Стоимость переобучения

Параметр не постулируется, а вычисляется как точка безубыточности
`C* = выгода / число переобучений`: от 6,1 до 38,9 млн $ в зависимости от
стратегии и окна.

Для масштаба стоимость оценена снизу вверх по данным Бюро трудовой статистики США
за период наблюдения. Профессия «Data Scientists» (SOC 15-2051) введена в
классификацию только в 2018 году, поэтому использован ближайший аналог —
«Statisticians» (SOC 15-2041): средняя годовая зарплата 118 340 $ в отрасли
небанковского кредитования (NAICS 522200), доля льгот 30,2 % полной компенсации.

| Сценарий | Трудоёмкость | Стоимость |
|---|---|---|
| Автоматизированный пайплайн | 0,25 чел-мес | 3 532 $ |
| Типовой | 1,5 чел-мес | 21 193 $ |
| Полная независимая валидация (SR 11-7) | 4 чел-мес | 56 514 $ |

Вычислительные затраты измерены напрямую: обучение занимает 3,1 с, скоринг
месячной выборки — 0,1 с, то есть в стоимости переобучения ими можно пренебречь.

Даже при самом дорогом сценарии запас до точки безубыточности — от 108 до 688 раз.

## Воспроизведение

```bash
pip install -r requirements.txt
cd src

# 1. Панель кредитов и выборка отклонённых заявок
python build_panel_ext.py
python build_rejected.py

# 2. Базовая модель и walk-forward для S1
python stage3_baseline.py

# 3. Сравнение шести стратегий
python stage4_strategies.py

# 4. Предрасчёт моделей (по одному окну за раз: нужно около 2 ГБ памяти)
for tw in 12 18 24 36; do python stage5a_cache.py $tw; done

# 5. Проверка гипотез для каждого окна
for tw in 12 18 24 36; do python stage5b_hypotheses.py $tw; done

# 6. Сводка по чувствительности к длине окна
python stage6_window_sensitivity.py
```

Шаг 4 — самый долгий: примерно 5 минут на окно. Запускайте окна по очереди:
параллельный запуск четырёх на машине с 8 ГБ памяти обрывается.

Промежуточные файлы складываются в `work/` и занимают около 300 МБ; в репозиторий
они не коммитятся. Расположение каталогов переопределяется переменными окружения
`SCORING_DATA`, `SCORING_WORK` и `SCORING_RESULTS` (см. `src/paths.py`).

## Ограничения

- **Только одобренные заявки имеют исход.** Lending Club отсеивает 71–95 %
  входящего потока, поэтому модель обучается на выжившей выборке. Это смещение
  отбора, которое невозможно устранить на этих данных.
- **P2P-платформа, а не банк.** Регулирование, состав заёмщиков и экономика
  отличаются от классического банковского скоринга.
- **LGD около 0,9**, тогда как для необеспеченной розницы в литературе типичны
  0,30–0,60. Причина в том, что взыскание по необеспеченным потребительским
  займам в США возвращает очень мало.
- **Дрейф смешан с изменениями политики кредитора** и сезонностью, поэтому его
  чистый эффект не выделяется.
- **Возвраты у поздних когорт неполны**, что завышает расчётный LGD.

Выводы формулируются в относительных величинах (выгода против S1, точка
безубыточности), а не в абсолютных значениях PD или LGD. Поэтому отраслевая
специфика влияет на масштаб чисел, но не на сравнение стратегий между собой.
